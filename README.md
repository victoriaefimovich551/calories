# Калории — Telegram Mini App

Счётчик калорий, который открывается прямо внутри Telegram. Сервер не нужен:
это статическая страница, а данные хранятся в облаке Telegram пользователя
(CloudStorage) и синхронизируются между его устройствами.

После публикации (GitHub Pages) приложение доступно по адресу
`https://mylaba.com/calories/`.

## Как подключить к боту

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username бота.
2. `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App**
   → отправьте ссылку `https://mylaba.com/calories/`.
   У бота появится кнопка «Открыть» в профиле и в списке чатов.
3. (По желанию) **Bot Settings** → **Menu Button** → **Configure menu button** → та же ссылка
   и подпись, например «Калории» — кнопка появится слева от поля ввода в чате с ботом.

Токен бота для работы приложения не нужен — никуда его не вставляйте и не публикуйте.

## Что умеет

- дневник по приёмам пищи (завтрак, обед, ужин, перекус), любые прошедшие дни;
- поиск по ~190 базовым продуктам и ~8,7 тыс. товаров из магазинов, свои продукты, недавние;
- расчёт нормы калорий и БЖУ по формуле Миффлина — Сан-Жеора или своя норма;
- статистика за 7 дней;
- оформление подстраивается под тему Telegram.

## Файлы

- `index.html` — приложение (разметка, стили, логика);
- `foods.js` — базовые продукты и блюда (ккал и БЖУ на 100 г), можно дополнять;
- `products.js` — около 8,7 тыс. товаров из российских магазинов (в том числе марки
  ВкусВилл, Перекрёсток, Пятёрочка, Магнит и др.); подгружается при открытии поиска;
- `build_products.py` — скрипт, которым собран `products.js` (для обновления базы,
  приложению не нужен).

## Источник данных

Товары взяты из открытой базы [Open Food Facts](https://world.openfoodfacts.org)
(лицензия [ODbL](https://opendatacommons.org/licenses/odbl/1-0/)). Её наполняют
добровольцы, поэтому в ней есть не весь ассортимент магазинов и встречаются неточности.
